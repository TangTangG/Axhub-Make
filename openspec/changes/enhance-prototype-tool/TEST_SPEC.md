## 一、Axure 导出可编辑性验收标准

### 1.1 可编辑性定义

| 级别 | 定义 | 验收标准 |
|------|------|---------|
| L1 完全可编辑 | 文本、尺寸、位置、样式、交互均可编辑 | 导入 Axure 后，用户可以直接修改所有属性 |
| L2 部分可编辑 | 文本和尺寸可编辑，样式部分可编辑 | 导入 Axure 后，文本和尺寸可直接修改，样式需通过格式刷 |
| L3 占位可编辑 | 仅作为占位符，可替换内容 | 导入 Axure 后，可双击替换文本/图片 |
| L4 不可编辑 | 导出为图片 | 导入 Axure 后，为静态图片，仅可移动/缩放 |

### 1.2 组件可编辑性矩阵

| 组件 | 目标级别 | 验收操作路径 |
|------|---------|-------------|
| 矩形 | L1 | 导入 → 修改尺寸 → 修改颜色 → 修改圆角 |
| 文本 | L1 | 导入 → 双击修改文本 → 修改字体/字号/颜色 |
| 按钮 | L1 | 导入 → 修改文本 → 修改颜色 → 添加交互 |
| 输入框 | L1 | 导入 → 修改占位文本 → 修改尺寸 → 修改边框 |
| 下拉选择 | L1 | 导入 → 修改选项列表 → 修改选中项 |
| 单选框 | L1 | 导入 → 修改选项 → 修改选中状态 |
| 复选框 | L1 | 导入 → 修改标签 → 修改选中状态 |
| 表格 | L2 | 导入 → 修改单元格文本 → 修改行高/列宽 → 简单样式 |
| 开关 | L1 | 导入 → 修改标签 → 切换状态 |
| 导航栏 | L1 | 导入 → 修改菜单项 → 修改 Logo → 修改样式 |
| 标签页 | L1 | 导入 → 修改标签文本 → 切换标签 |
| 卡片 | L1 | 导入 → 修改标题/内容 → 修改阴影/圆角 |
| 图表 | L3 | 导入 → 替换图片 → 修改占位文本 |
| 地图 | L3 | 导入 → 替换图片 → 修改占位文本 |
| 富文本 | L2 | 导入 → 修改文本 → 部分格式保留 |

### 1.3 Axure 版本兼容性

| Axure 版本 | 支持状态 | 测试要求 |
|-----------|---------|---------|
| Axure RP 10 | ✅ 主要支持 | 全部组件测试 |
| Axure RP 9 | ⚠️ 兼容支持 | 基础组件测试，复杂组件降级 |
| Axure RP 8 | ❌ 不支持 | 提示用户升级 |

### 1.4 异常场景测试

| 场景 | 预期行为 | 验收标准 |
|------|---------|---------|
| Bridge 未启动 | 提示用户启动 Bridge | 显示引导弹窗，提供复制剪贴板备选 |
| Bridge 版本不匹配 | 提示版本不兼容 | 显示版本要求，阻止导出 |
| 导出超时 | 提示导出失败 | 显示错误信息，支持重试 |
| 组件类型未知 | 自动降级 | 导出为占位矩形，日志记录警告 |
| CSS 属性不支持 | 自动忽略 | 使用默认值，日志记录警告 |

## 二、多模式预览验收标准

### 2.1 三种模式一致性

| 检查项 | 标准 | 测试方法 |
|--------|------|---------|
| 布局一致性 | 三种模式下组件位置偏差 ≤1px | 截图对比 |
| 颜色一致性 | 三种模式下颜色值相同 | 取色器对比 |
| 字体一致性 | 三种模式下字体渲染一致 | 截图对比 |
| 交互一致性 | iframe 和 HTML 交互一致 | 人工测试 |
| 图片保真度 | 图片导出与屏幕显示一致 | 截图对比 |

### 2.2 HTML 导出验收标准

| 检查项 | 标准 |
|--------|------|
| 文件大小 | ≤5MB（含内联资源） |
| 离线打开 | Chrome/Firefox/Safari/Edge 可正常打开 |
| 资源加载 | 无外部依赖时 3s 内完成渲染 |
| 交互保持 | 按钮点击、链接跳转正常 |
| 响应式 | 1280/1440/1920 宽度下布局正常 |

### 2.3 图片导出验收标准

| 检查项 | 标准 |
|--------|------|
| 分辨率 | 1x/2x/3x 可选 |
| 格式 | PNG/SVG 可选 |
| 背景 | 透明/白色/页面底色可选 |
| 范围 | 整页/选区可选 |
| 字体 | SVG 导出嵌入字体 |

## 三、上游同步验收标准

### 3.1 同步健康度指标

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| 自动同步成功率 | ≥70% | CI 成功次数/总次数 |
| 冲突率 | ≤30% | 冲突次数/同步次数 |
| 同步后测试通过率 | 100% | 测试通过数/总测试数 |
| 平均解决冲突时间 | ≤2h | 从冲突到解决的时间 |

### 3.2 同步后必过测试

- [ ] 项目可正常构建（`npm run build`）
- [ ] 单元测试全部通过（`npm test`）
- [ ] E2E 测试全部通过（`npm run test:e2e`）
- [ ] Axure 导出回归测试通过
- [ ] HTML 导出功能正常
- [ ] 图片导出功能正常

### 3.3 冲突处理流程

```
检测冲突
    │
    ▼
┌─────────────┐
│ 自动解决？    │ ──是──▶ 重新生成 patch，继续测试
│ (patches/)   │
└─────────────┘
    │ 否
    ▼
┌─────────────┐
│ 人工介入     │ ──▶ 创建 issue，通知维护者
│             │     暂停自动同步，等待修复
└─────────────┘
```

### 3.4 回滚策略

| 场景 | 回滚方式 | 验收标准 |
|------|---------|---------|
| 同步引入 bug | `git tag` + `git reset --hard` 回滚 | 回滚后功能正常 |
| 严重冲突无法解决 | 放弃本次同步，保持当前版本 | 记录冲突原因 |
| 上游仓库不可用 | 使用本地缓存版本 | 功能不受影响 |

### 3.5 上游 API 变更检测

| 检测项 | 检测方式 | 响应动作 |
|--------|---------|---------|
| 导出函数签名变更 | CI 构建时类型检查 | 标记为不兼容，暂停同步 |
| 组件接口变更 | 对比 `axure-types.ts` 版本 | 生成 API 变更报告 |
| 新增废弃标记 | 扫描 `@deprecated` 注释 | 记录迁移计划 |

## 四、性能与容量验收标准

### 4.1 性能指标

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| 首屏渲染时间 | ≤3s | Lighthouse |
| AI 生成响应时间 | ≤10s | 从输入到画布可预览 |
| 单页 HTML 导出时间 | ≤5s | 计时 |
| 单页图片导出时间 | ≤3s | 计时 |
| 批量导出 10 页时间 | ≤30s | 计时 |
| 大页面（100+组件）渲染 | ≤5s | 计时 |
| 内存占用 | ≤500MB | Chrome DevTools |

### 4.2 容量上限

| 限制项 | 上限值 | 超限处理 |
|--------|--------|---------|
| 单页组件数 | 500 个 | 超出提示「页面组件过多，建议拆分」 |
| 组件嵌套层级 | 8 层 | 超出提示「嵌套过深，建议扁平化」 |
| 表格行数 | 1000 行 | 超出启用虚拟滚动 |
| 表格列数 | 50 列 | 超出提示「列数过多，建议横向滚动」 |
| 单项目页面数 | 20 页 | 超出提示「项目过大，建议拆分」 |
| 项目文件大小 | 5MB | 超出提示「项目过大，建议清理未使用资源」 |
| 导出 Axure 文件大小 | 10MB | 超出启用分片传输 |
| 图片资源大小 | 2MB/张 | 超出自动压缩 |

### 4.3 大数据量测试

| 场景 | 数据规模 | 验收标准 |
|------|---------|---------|
| 大表格 | 1000 行 × 20 列 | 渲染流畅，滚动不卡顿 |
| 长列表 | 500 项 | 虚拟滚动，内存稳定 |
| 多页面 | 20 页 × 50 组件 | 页面切换流畅 |
| 复杂嵌套 | 8 层嵌套 × 10 组件/层 | 渲染正确，无错位 |

## 六、异常处理验收标准

### 6.1 AI 生成异常

| 异常场景 | 预期行为 | 用户提示 |
|---------|---------|---------|
| 非法 JSON 响应 | 解析失败，提示重试 | "AI 响应格式错误，请重试" |
| 未知组件类型 | 降级为占位矩形 | "未知组件 [类型]，已降级为占位" |
| 循环嵌套组件 | 检测到循环，中断生成 | "组件嵌套循环，请调整需求" |
| 空响应 | 提示重新输入 | "AI 未返回内容，请重新描述需求" |
| 超时（>30s） | 取消请求，提示重试 | "生成超时，请重试" |
| AI 生成失败 | 显示错误信息，支持重试 | "生成失败，请重试" |

### 6.2 网络异常

| 异常场景 | 预期行为 | 用户提示 |
|---------|---------|---------|
| 断网状态 | 离线缓存可用 | "离线模式，部分功能受限" |
| 请求超时 | 自动重试 3 次 | "网络缓慢，正在重试" |
| 服务器错误 | 友好提示 | "服务暂时不可用，请稍后重试" |
| 网络断开 | 本地缓存，恢复后同步 | "网络已断开，数据已保存到本地" |

### 6.3 导出异常

| 异常场景 | 预期行为 | 用户提示 |
|---------|---------|---------|
| Bridge 未启动 | 降级为剪贴板复制 | "Axure Bridge 未启动，已复制到剪贴板" |
| Bridge 版本不兼容 | 提示升级 | "Axure 版本过低，请升级至 10.0+" |
| 导出超时 | 取消导出，提示重试 | "导出超时，请检查 Axure 是否响应" |
| 大文件导出失败 | 分片重试 | "文件较大，正在分片传输" |
| 导出中断 | 保留已导出部分 | "导出中断，已保存部分内容" |

### 6.4 渲染异常

| 异常场景 | 预期行为 | 用户提示 |
|---------|---------|---------|
| 组件渲染失败 | 显示错误占位 | "组件渲染失败，已降级显示" |
| 图片加载失败 | 显示占位图 | 显示默认占位图 + 重试按钮 |
| 字体加载失败 | 降级为系统字体 | 自动使用系统字体渲染 |
| 内存不足 | 提示刷新页面 | "内存不足，请刷新页面" |

## 七、数据埋点验收标准

### 7.1 必埋事件

| 事件 | 触发时机 | 属性 |
|------|---------|------|
| `app_open` | 应用打开 | timestamp, user_agent |
| `ai_generate_start` | 点击生成按钮 | prompt_length, timestamp |
| `ai_generate_success` | 生成成功 | duration, component_count |
| `ai_generate_fail` | 生成失败 | error_message, duration |
| `export_axure_start` | 点击 Axure 导出 | component_count |
| `export_axure_success` | 导出成功 | duration, file_size |
| `export_axure_fail` | 导出失败 | error_message |
| `export_html` | 点击 HTML 导出 | file_size, duration |
| `export_image` | 点击 图片导出 | format, dpi, duration |
| `preview_mode_switch` | 切换预览模式 | from_mode, to_mode |

### 7.2 核心指标

| 指标 | 计算方式 | 目标值 |
|------|---------|--------|
| 激活率 | 首次导出成功用户数/首次访问用户数 | ≥40% |
| AI 采纳率 | 直接导出数/AI 生成成功数 | ≥60% |
| 导出成功率 | 导出成功数/导出尝试数 | ≥90% |
| 周留存率 | 第 2 周活跃用户数/第 1 周新增用户数 | ≥30% |
