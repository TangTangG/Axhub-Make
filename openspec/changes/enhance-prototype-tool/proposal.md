# 增强原型工具：AI 生成 + Axure 导入增强 + 多模式预览

## 为什么

Axhub-Make 是一个优秀的 AI 原型生成工具，但存在以下不足：

1. **Axure 导入组件类型有限**：当前主要支持基础组件，缺乏表单组件（下拉/单选/复选/表格）和布局组件（导航/标签页/卡片）的完整支持
2. **预览方式单一**：主要依赖浏览器内嵌预览，缺乏独立 HTML 文件导出和静态图片预览
3. **组件库覆盖不足**：缺少完整的企业级组件库

## 做什么

基于 Axhub-Make fork 开发，**v1.0 聚焦导出能力增强**，实现：

### 1. AI 生成原型（复用上游能力）

- 输入功能需求文档，AI 自动生成原型页面
- 复用 Axhub-Make 现有 ACP (AI Canvas Protocol) 和 Excalidraw 画布
- 生成结果直接可在浏览器中预览

### 2. 增强 Axure 导入

- **组件类型扩展**：
  - 基础组件：矩形、文本、按钮、输入框、图片（已有，增强）
  - 表单组件：下拉选择、单选框、复选框、表格、开关、滑块
  - 布局组件：导航栏、标签页、卡片、分割线、栅格容器
  - 高级组件：图表、地图、富文本（尽力而为，接受降级）
- **导入后可编辑**：所有组件在 Axure RP 中保持原生可编辑状态（非图片）
- **样式映射**：CSS 样式 → Axure 样式属性的完整映射
- **降级策略**：无法映射的组件/样式自动降级为占位矩形 + 图注

### 3. 多模式预览

- **iframe 内嵌预览**：浏览器内直接预览交互效果（已有，增强）
- **独立 HTML 导出**：导出完整 HTML 文件，可离线打开、分享、部署
- **静态图片导出**：导出 PNG/SVG 高清图片，用于文档嵌入、快速分享

### 4. 完整组件库

- **基础组件**：矩形、文本、按钮、输入框、图片、链接
- **表单组件**：下拉、单选、复选、表格、日期选择、上传
- **布局组件**：导航、标签页、卡片、模态框、抽屉、栅格
- **高级组件**：图表（柱状图/折线图/饼图）、地图、富文本、视频

## 用户场景

### 目标用户

- **产品经理**：快速将需求文档转为可交互原型，导出 Axure 继续细化
- **UI 设计师**：AI 生成初稿，在 Axure 中精细调整
- **前端开发**：获取设计规范（颜色/字体/间距），快速还原页面

### 核心工作流

```
用户输入需求文档
    │
    ▼
┌─────────────┐
│  AI 生成模块  │ ──▶ 生成 Excalidraw 画布（上游能力）
└─────────────┘
    │
    ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  iframe 预览 │     │  HTML 导出   │     │  图片导出    │
│  (实时渲染)  │     │  (独立文件)  │     │  (PNG/SVG)  │
└─────────────┘     └─────────────┘     └─────────────┘
    │
    ▼
┌─────────────┐
│ Axure 导出   │ ──▶ Axure Bridge ──▶ Axure RP (可编辑)
└─────────────┘
```

## 成功标准

1. **Axure 导出**：基础组件 100% 可编辑，表单组件 90%+ 可编辑，布局组件 80%+ 可编辑，高级组件尽力而为
2. **预览导出**：支持 iframe、独立 HTML、静态图片三种模式
3. **组件库**：覆盖企业级常见组件 ≥20 种，每种组件有完整的状态规范
4. **上游同步**：每周自动 sync，冲突率 ≤30%，同步后核心功能测试通过率 100%
5. **性能**：单页导出时间 ≤5s，HTML 文件大小 ≤5MB（含内联资源）
6. **数据埋点**：覆盖激活漏斗、AI 采纳率、导出成功率等核心指标

## 技术约束

1. **上游同步优先**：所有本地修改必须隔离，确保每周可自动 merge 上游更新
2. **不直接生成 .rp**：通过 Axure Bridge (localhost:32767) 实现
3. **组件树单一数据源**：AI 生成和导出都基于同一组件树
4. **CSS 样式作为中间格式**：所有组件最终渲染为 CSS，再映射到 Axure

## 风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| Axure Bridge 不可用 | 中 | 高 | 提供降级策略（复制剪贴板 + 手动粘贴） |
| 高级组件导出效果差 | 高 | 中 | 明确告知用户降级策略，提供占位符 |
| 上游更新导致冲突 | 中 | 高 | git subtree + patch-package，冲突自动检测 |
| CSS 映射不完整 | 高 | 中 | 建立映射表，未覆盖属性自动忽略并警告 |
