# Make Client Template 0.1.15 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare and verify the `@axhub/make-client` `0.1.15` release candidate with the renamed comment skill, shared comment-storage conventions, and preview-runtime fixes, without publishing externally.

**Architecture:** `client/template-manifest.json` remains the release boundary. The release helper copies approved runtime directories, packages only manifest-selected prototypes/resources/themes, and generates `.axhub/make/sidebar-tree.json` from the template seed rather than the current project tree.

**Tech Stack:** Node.js 22, pnpm 10, Node test runner, Vitest, fflate.

## Global Constraints

- Prepare template version `0.1.15` and tag metadata `make-client-template-v0.1.15`.
- Do not publish GitHub or Gitee releases.
- Do not modify `client/.axhub/make/sidebar-tree.json` or project-specific prototypes, PRDs, themes, or comment data.
- Include `handle-comments`; exclude `prototype-comments` even if a stale copy is present.
- Generate the packaged sidebar from `client/template-seed/.axhub/make/sidebar-tree.json` and `client/template-manifest.json`.
- Preserve unrelated staged, unstaged, and untracked changes.
