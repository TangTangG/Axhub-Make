# 警情热力图

## 📋 业务与功能

### 1.1 核心目标

警情热力图是一个基于地图的警情数据可视化分析平台，用于实时展示和分析警情分布、热点区域和趋势变化。核心价值包括：

- **空间可视化**：通过热力图和点位图直观展示警情空间分布
- **多维度分析**：支持按级别、类型、时间、单位等多维度查询和分析
- **热点识别**：自动识别警情高发区域，辅助警力部署
- **数据导出**：支持导出明细数据和统计报表，便于深度分析
- **区域管理**：支持自定义区域收藏，方便重复查询

### 1.2 功能清单

#### 左侧查询面板功能
- **多维度查询**：支持按警情级别、类型、报警时间、报警时段、警情标签、责任单位、下属中队、警情信息进行查询
- **统计维度切换**：支持切换不同的统计维度进行数据聚合
- **展示模式切换**：支持热力图和点位图两种展示模式

#### 中间地图区域功能
- **热力图展示**：根据查询条件展示警情热力分布
- **点位图展示**：以点位形式展示警情分布
- **聚合展示**：支持地图点位聚合，避免重叠
- **地图控制**：
  - 聚合距离设置
  - 热力图参数调整（半径、透明度等）
  - 自定义区域选择

#### 右侧排行与统计功能
- **警情发生地排行**：
  - 支持按路口或路段切换展示
  - 展示排名、名称、警情数
  - 支持导出排行榜数据
  
- **统计报表**：
  - 违法行为统计报表
  - 车辆分类统计报表
  - 环比分析（上周、上月）
  - 同比分析（去年）
  - 自定义同环比时间
  
- **导出功能**：
  - 一键导出警情明细
  - 导出统计报表
  
- **区域收藏**：
  - 保存自定义区域
  - 快速选择已收藏区域

### 1.3 交互要点

- **查询操作**：选择查询条件 → 点击查询 → 更新地图和统计数据
- **模式切换**：点击热力图/点位图按钮 → 切换展示模式 → 更新地图显示
- **地图交互**：
  - 缩放地图 → 自动调整聚合级别
  - 点击聚合点 → 展开显示详细点位
  - 选择自定义区域 → 高亮显示区域范围
- **排行查看**：点击排行项 → 地图定位到对应位置 → 显示详细信息
- **报表查看**：点击查看报表 → 弹窗展示统计报表 → 支持导出
- **区域收藏**：绘制自定义区域 → 点击收藏 → 输入名称 → 保存区域

### 2.2 数据来源

- **数据类型**：警情数据、地理数据、统计数据
- **数据源**：
  - 警情数据表：警情基本信息、位置信息、时间信息
  - 地理数据表：路口信息、路段信息、区域边界
  - 统计数据表：警情统计、违法行为统计、车辆分类统计
- **关键字段**：
  - `incidentId`: 警情ID
  - `incidentLevel`: 警情级别
  - `incidentType`: 警情类型
  - `alarmTime`: 报警时间
  - `alarmPeriod`: 报警时段
  - `incidentTags`: 警情标签
  - `responsibleUnit`: 责任单位
  - `squad`: 下属中队
  - `incidentInfo`: 警情信息
  - `location`: 位置信息（经纬度）
  - `intersection`: 路口名称
  - `roadSection`: 路段名称
  - `violationType`: 违法行为类型
  - `vehicleType`: 车辆类型

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：三栏布局（左侧查询 + 中间地图 + 右侧统计）
- **容器宽度**：流式，最大宽度 1920px
- **关键尺寸**：
  - 左侧查询面板：宽度 320px，固定宽度
  - 中间地图区域：宽度自适应，最小宽度 800px
  - 右侧统计面板：宽度 360px，固定宽度
  - 面板间距：16px
  - 内边距：16px

### 3.2 响应式适配

- **超大屏（≥1600px）**：
  - 左侧：320px
  - 中间：自适应
  - 右侧：360px

- **大屏（1200-1599px）**：
  - 左侧：280px
  - 中间：自适应
  - 右侧：320px

- **中屏（768-1199px）**：
  - 左侧：可折叠
  - 中间：100%
  - 右侧：可折叠

## 🎨 视觉规范

### 4.1 设计规范来源

**设计规范来源**：内置 interface-design

**说明**：采用深色主题设计，适合地图可视化场景，突出数据展示。

### 4.2 自定义设计要点

**自定义色彩**：
- 主背景：#0A0E1A（深蓝黑）
- 面板背景：#141B2D（深蓝灰）
- 边框色：#1E2738（深灰蓝）
- 文字色：#E5E7EB（浅灰）
- 主色调：#3B82F6（蓝色）
- 热力图色阶：蓝色 → 绿色 → 黄色 → 橙色 → 红色
- 成功色：#10B981（绿色）
- 警告色：#F59E0B（橙色）
- 错误色：#EF4444（红色）

**自定义尺寸**：
- 标题字号：16px
- 正文字号：14px
- 小字号：12px
- 面板圆角：8px
- 面板内边距：16px

**其他自定义规范**：
- 地图使用深色底图样式
- 热力图使用渐变色阶
- 点位使用圆形标记，不同级别使用不同颜色
- 聚合点显示数量，使用圆形背景

### 4.3 组件状态

- **默认态（default）**：面板正常显示，数据清晰可见
- **悬停态（hover）**：面板边框高亮，按钮显示悬停效果
- **加载态（loading）**：显示加载动画，地图显示加载提示
- **异常态（error）**：异常数据使用红色标识，显示错误提示

## ⚙️ Axure API 说明

### 5.1 事件列表（eventList）

| 事件名称 | Payload 类型 | 触发时机 | 说明 |
|---------|-------------|---------|------|
| `onQuery` | `JSON string` | 点击查询按钮时触发 | 返回当前查询条件 |
| `onMapClick` | `JSON string` | 点击地图点位时触发 | 返回当前点位信息与显示模式 |
| `onAreaSelect` | `JSON string` | 选择已保存区域或保存新区域时触发 | 返回区域 ID 与名称 |
| `onRankClick` | `JSON string` | 点击排行项查看报表时触发 | 返回排行项信息 |
| `onExport` | `string` | 点击导出按钮或执行导出动作时触发 | 返回导出类型 |

### 5.2 动作列表（actionList）

| 动作名称 | Params 类型 | 参数说明 | 功能描述 |
|---------|------------|---------|---------|
| `setQueryConditions` | `JSON string` | 查询条件对象，例如 `{"level":"1","keyword":"事故"}` | 设置查询条件 |
| `setMapCenter` | `JSON string` | 地图中心点，例如 `{"lat":39.9042,"lng":116.4074}` | 设置地图中心点 |
| `setMapZoom` | `number string` | 缩放级别，例如 `12` | 设置地图缩放级别 |
| `toggleDisplayMode` | `string` | `'heatmap'` \| `'point'` | 切换展示模式 |
| `highlightArea` | `string` | 区域ID | 高亮显示指定区域 |
| `exportData` | `string` | 导出类型 | 导出数据 |

### 5.3 变量列表（varList）

| 变量名称 | 类型 | 默认值 | 说明 |
|---------|-----|-------|------|
| `display_mode` | `string` | `'heatmap'` | 当前展示模式（热力图/点位图） |
| `query_conditions` | `object` | 见默认查询条件 | 当前查询条件对象 |
| `map_center` | `object` | `{lat: 39.9042, lng: 116.4074}` | 地图中心点 |
| `map_zoom` | `number` | `12` | 地图缩放级别 |
| `selected_area` | `object \| null` | `null` | 当前选中的自定义区域 |
| `saved_areas` | `array` | `[]` | 已保存的区域列表 |
| `rank_type` | `string` | `'intersection'` | 当前排行维度 |
| `selected_rank` | `string \| null` | `null` | 当前报表弹窗对应的排行名称 |
| `report_visible` | `boolean` | `false` | 统计报表弹窗是否打开 |

**命名规范**：使用 snake_case（小写字母、数字、下划线）

### 5.4 配置项列表（configList）

| 配置项名称 | 类型 | 默认值 | 说明 |
|----------|-----|-------|------|
| `defaultZoom` | `number` | `12` | 默认地图缩放级别 |
| `heatmapRadius` | `number` | `25` | 热力图半径 |
| `heatmapOpacity` | `number` | `0.8` | 热力图透明度 |
| `clusterDistance` | `number` | `50` | 聚合距离（像素） |

### 5.5 数据项列表（dataList）

**警情数据结构**：
```typescript
{
  incidentId: string;           // 警情ID
  lat: number;                  // 纬度
  lng: number;                  // 经度
  level: string;                // 警情级别
  type: string;                 // 警情类型
  count: number;                // 警情数量/热力值
}
```

**排行数据结构**：
```typescript
{

}
```

**统计报表数据结构**：
```typescript
{
  category: string;             // 分类
  count: number;                // 数量
  percentage: number;           // 占比
  weekOverWeek: number;         // 环比上周
  monthOverMonth: number;       // 环比上月
  yearOverYear: number;         // 同比去年
}
```
